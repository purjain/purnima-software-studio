01 / THE STACK

Built with intention.

HTML + JavaScript

Semantic page structure, interactive project filters, client-side view switching, and a responsive navigation system.

Modern CSS

Midnight-inspired design tokens, layered gradients, neon glow treatments, responsive grids, animation keyframes, and a custom illustrated café scene built entirely with CSS and HTML.

Accessible interaction

Descriptive labels, keyboard-accessible controls, reduced-motion preferences, and mobile-friendly layouts.

Static hosting and version-controlled deployment through GitHub Actions.
